# csi-spl-cnf

`csi-spl/<env>.env.yaml` is the configuration of the spool, one file per env
(`dev`, `prd`). Everything under `csi-spl/<env>/tf/` and every `*.env.json` is
GENERATED by tpl-gen (`cd ../csi-spl-iac && ENV=<env> ./run -a do_tpl_gen`):
edit the yaml, re-render, commit both.

Not here, by design: org/folder id, billing account, operator identity, keys.
