**Τι είναι**

Ο εξερευνητής Εγγράφων (Docs explorer) είναι ένα εγγενές πρόγραμμα προβολής για τα αρχεία markdown του αποθετηρίου σας. Βρίσκεται κάτω από τη «Βοήθεια» στην αριστερή γραμμή πλοήγησης και αποδίδει αρχεία readme, προδιαγραφές και άλλα αρχεία `.md` απευθείας στην εφαρμογή.

**Γιατί να το χρησιμοποιήσετε**

Εξαλείφει την ανάγκη να φύγετε από τον χώρο εργασίας σας ή να μεταβείτε σε εξωτερική πηγή όπως το GitHub για να διαβάσετε την τεκμηρίωση του έργου. Όλα τα αρχεία εμφανίζονται με το εγγενές θέμα της εφαρμογής.

**Πώς να το χρησιμοποιήσετε**

Κάντε κλικ στο εικονίδιο Έγγραφα. Σε ευρείες οθόνες, ο εξερευνητής ανοίγει σε δύο παράθυρα: ένα διαδραστικό δέντρο φακέλων στα αριστερά και το πρόγραμμα προβολής εγγράφων στα δεξιά. Μπορείτε να αναπτύξετε φακέλους για να βρείτε έγγραφα ή να κάνετε κλικ σε συνδέσμους μέσα στα έγγραφα για πλοήγηση. Σε τηλέφωνο, βλέπετε μία μόνο στήλη με το κουμπί «Φάκελοι» για εναλλαγή του εξερευνητή πάνω από το έγγραφο. Μπορείτε εύκολα να κοινοποιήσετε συνδέσμους, καθώς τα URL ακολουθούν τη δομή `/docs/<repo path>`.

**Ο παλιός τρόπος**

Προηγουμένως, οι χρήστες έπρεπε να πλοηγηθούν στον εξωτερικό κεντρικό υπολογιστή του αποθετηρίου ή να διαβάσουν μη επεξεργασμένα αρχεία markdown τοπικά για να δουν την τεκμηρίωση του έργου.

**Ο νέος τρόπος**

Τα έγγραφα πλέον αναλύονται και εμφανίζονται όμορφα μέσα στον χώρο εργασίας. Το πρόγραμμα προβολής υποστηρίζει σχετική δρομολόγηση για συνδέσμους μεταξύ αρχείων και διατηρεί τη θέση σας διαισθητικά.
