**Τι είναι**

Το παράθυρο διαλόγου Σημειώσεις έκδοσης είναι ένας αποκλειστικός ιχνηλάτης αρχείου καταγραφής αλλαγών. Εξάγει σημειώσεις έκδοσης σε απλή γλώσσα και τεχνικούς όρους από τα trailers των μηνυμάτων υποβολής (commit) και τα παρουσιάζει απευθείας στον χώρο εργασίας.

**Γιατί να το χρησιμοποιήσετε**

Κρατάει τους πάντες—από τους καθημερινούς χρήστες μέχρι τους μηχανικούς—ενήμερους για το τι άλλαξε, πώς άλλαξε και γιατί, χωρίς να χρειάζεται να ψάξουν στα αρχεία καταγραφής του git ή σε εξωτερικά εργαλεία παρακολούθησης αλλαγών.

**Πώς να το χρησιμοποιήσετε**

Κάντε κλικ στην έκδοση της εφαρμογής στο κάτω μέρος του αριστερού πλαισίου (ή στη γραμμή κατάστασης σε ένα τηλέφωνο) και επιλέξτε «Release notes» (Σημειώσεις έκδοσης). Ανοίγει ένα παράθυρο διαλόγου που δείχνει τις 30 πιο πρόσφατες αλλαγές. Κάντε κλικ σε οποιαδήποτε αλλαγή για να διαβάσετε την πλήρη περιγραφή της τόσο με απλά λόγια όσο και με τεχνικούς όρους. Μπορείτε να χρησιμοποιήσετε τα `j` και `k` για να πλοηγηθείτε στις γραμμές σε υπολογιστή, ή να κάνετε κλικ στο «Load older versions» (Φόρτωση παλαιότερων εκδόσεων) στο κάτω μέρος για να δείτε παλαιότερες εγγραφές. Κάθε σημείωση μπορεί να κοινοποιηθεί μέσω ενός σταθερού συνδέσμου `/releases/<ref>`.

**Ο παλιός τρόπος**

Οι αλλαγές συχνά παρακολουθούνταν χειροκίνητα σε εξωτερικά έγγραφα, ή οι χρήστες έπρεπε να βασίζονται σε ξεχωριστές ανακοινώσεις και στο ιστορικό του git για να κατανοήσουν τα νέα χαρακτηριστικά και τις διορθώσεις.

**Ο νέος τρόπος**

Οι σημειώσεις έκδοσης είναι πλέον ενσωματωμένες αυτόματα. Κάθε έγκυρη αλλαγή αντλείται απευθείας από τα commit trailers, διασφαλίζοντας ότι το αρχείο καταγραφής αλλαγών είναι πάντα ακριβές και διαθέσιμο σε όλους σε μια ευανάγνωστη διάταξη πίνακα, ακριβώς στο περιβάλλον όπου εργάζονται.
