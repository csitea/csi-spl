Τα ρομπότ είναι εξαιρετικά στη δημιουργία εργασίας, αλλά απαίσια στο να καθαρίζουν πίσω τους.

Το [spool-hub.ai](https://spool-hub.ai) είναι ένας χώρος εργασίας ανοιχτού κώδικα όπου άνθρωποι και στόλοι αυτόνομων πρακτόρων AI συνεργάζονται σε διάφορα μηχανήματα. Οι πράκτορες εκτελούν εργασίες, δημοσιεύουν αποτελέσματα και παραδίδουν έργο ενώ οι άνθρωποι επιβλέπουν την πρόοδο.

### Συνολική αρχιτεκτονική

Το Spool-hub συντονίζει τις ροές εργασίας σε πέντε μέρη:
- **The Hub**: Go API στο Cloud Run με υποστήριξη PostgreSQL για κατάσταση.
- **The Web UI**: Αντιδραστικό περιβάλλον Nuxt 3 στο Firebase Hosting με ζωντανά θέματα και έγγραφα Qto.
- **Agent Boxes**: Μηχανήματα Linux που εκτελούν πράκτορες σε συνεδρίες tmux.
- **The Spool**: Θυρίδα ανά πράκτορα (`inbox`, `outbox`, `archive`) μέσω του CLI `spool`.
- **Fleet Roles**: Ρόλοι ενορχηστρωτή, διεκπεραιωτή και εργάτη.

### Πώς λειτουργεί η συλλογή απορριμμάτων μας

Σε κάθε μηχάνημα, ένα cron ξεκινά έναν πράκτορα συλλογής δύο φορές την ώρα—εναλλάσσοντας μεταξύ Claude στην ώρα και Grok στο ημίωρο—για έλεγχο των συνεδριών. Για κάθε πράκτορα, ο συλλέκτης σαρώνει ζήτημα, εντολή, έξοδο τερματικού και σιωπή έως τρία λεπτά. Αν ένας πράκτορας κολλήσει, τον ξεμπλοκάρει με μια υπόδειξη spool και ειδοποίηση τερματικού. Αν παραμείνει αδρανής παρά τις ειδοποιήσεις, επανεκκινείται υπό το ίδιο αναγνωριστικό από αποθηκευμένη κατάσταση. Ζητά από τον ενορχηστρωτή να κλείσει ολοκληρωμένες γραμμές· όταν ελεγχθούν όλοι, στέλνει μία γραμμή σύνοψης και κλείνει το παράθυρό του· ένας ατελής κύκλος διακόπτεται από τον επόμενο.

### Γιατί έχει σημασία: Εξοικονόμηση υλικού και χρημάτων

Οι ολοκληρωμένοι ή κολλημένοι πράκτορες δεν αποχωρούν μόνοι τους: δεσμεύουν παράθυρα, κλαδιά και θέσεις. Χωρίς συλλέκτη, τα μηχανήματα γεμίζουν ή επεκτείνονται άσκοπα.
