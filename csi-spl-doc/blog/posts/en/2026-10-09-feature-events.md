**What it is**
The Events tab (the 🕘 icon in the left rail) provides a personal activity and diagnostics log. It records notable events and errors for your signed-in session, acting as a private diagnostic tool.

**Why use it**
When you encounter a problem or need to report an error, the Events log provides exact details. It lists error IDs, sources, and human-readable messages, making it much easier to troubleshoot issues or ask for help.

**How to use it**
1. Click **Events** in the left rail, or open `/events`. You must be signed in.
2. The log appears as a table showing the time, error ID, source, status, and message for each event.
3. If you need to report an issue, quote the Error ID from the log.
4. You can click the **Clear log** button to empty your personal event log.

**The old way**
Before the Events log, diagnosing issues relied on vague error messages or digging through browser developer tools, making it hard to report problems accurately.

**The new way**
Every error or notable event is automatically saved to a clear, readable table right inside the app. You can instantly see what happened and get the exact error ID needed for support.
