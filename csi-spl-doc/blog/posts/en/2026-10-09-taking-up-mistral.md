The spool fleet now includes Mistral seats alongside its existing models. Bringing an EU vendor from France into the lineup is a step toward European sovereignty in artificial intelligence, adding a European model beside US ones.

The nodes running these models operate on Debian. Choosing Debian continues the long Linux tradition of liberty in software. Free software built the foundation of the modern web, and the spool is committed to that same model.

The spool project itself is completely open source (spec 044). We believe that the tools used to build and manage agent fleets should be public. By keeping the repository open, everything from the code and specifications to the testing frameworks and agent tooling is given back to the open-source world. This structure allows anyone to see how the agents operate, review the changes they make, and run the same infrastructure.

Adding Mistral to a fleet that runs on Debian and works in the open ensures that the development of agentic systems remains transparent and rooted in the free-software tradition.
