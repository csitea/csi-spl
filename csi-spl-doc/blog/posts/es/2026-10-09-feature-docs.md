**Qué es**

El explorador de Documentos es un visor nativo para los archivos markdown de su repositorio. Ubicado bajo «Ayuda» en la barra lateral izquierda, procesa archivos readme, especificaciones y otros archivos `.md` directamente en la aplicación.

**Por qué usarlo**

Elimina la necesidad de salir de su espacio de trabajo o acudir a una fuente externa como GitHub para leer la documentación del proyecto. Todos los archivos se muestran con el tema nativo de la aplicación.

**Cómo usarlo**

Haga clic en el icono Documentos. En pantallas anchas, el explorador se abre en dos paneles: un árbol de carpetas interactivo a la izquierda y el visor de documentos a la derecha. Puede expandir carpetas para buscar documentos o hacer clic en los enlaces dentro de los documentos para navegar. En un teléfono, verá una sola columna con el botón «Carpetas» para alternar el explorador sobre el documento. Puede compartir enlaces fácilmente, ya que las URL siguen la estructura `/docs/<repo path>`.

**La forma anterior**

Anteriormente, los usuarios debían navegar hasta el host externo del repositorio o leer archivos markdown sin formato localmente para ver la documentación del proyecto.

**La nueva forma**

Ahora los documentos se analizan y se presentan de forma impecable dentro del espacio de trabajo. El visor admite enrutamiento relativo para enlaces entre archivos y mantiene su posición de forma intuitiva.
