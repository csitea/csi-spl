**Kas tas ir**

Dokumentu pārlūks (Docs explorer) ir iebūvēts skatītājs jūsu krātuves markdown failiem. Tas atrodas kreisās joslas sadaļā „Palīdzība“ un atveido readme failus, specifikācijas un citus `.md` failus tieši lietotnē.

**Kāpēc to izmantot**

Tas novērš nepieciešamību pamest darba telpu vai doties uz ārēju avotu, piemēram, GitHub, lai lasītu projekta dokumentāciju. Visi faili tiek attēloti lietotnes pamata motīvā.

**Kā to lietot**

Noklikšķiniet uz ikonas „Dokumenti“. Platos ekrānos pārlūks atveras divās rūtīs: interaktīvs mapju koks kreisajā pusē un dokumentu skatītājs labajā pusē. Varat izvērst mapes, lai atrastu dokumentus, vai noklikšķināt uz saitēm dokumentos, lai pārvietotos. Tālrunī redzama viena kolonna ar pogu „Mapes“, lai pārslēgtu pārlūku virs dokumenta. Varat ērti kopīgot saites, jo vietrāži URL atbilst struktūrai `/docs/<repo path>`.

**Vecais veids**

Iepriekš lietotājiem bija jādodas uz ārējo krātuves resursdatoru vai lokāli jālasa neapstrādāti markdown faili, lai skatītu projekta dokumentāciju.

**Jaunais veids**

Tagad dokumenti tiek parsēti un lieliski attēloti tieši darba telpā. Skatītājs atbalsta relatīvo maršrutēšanu saitēm starp failiem un intuitīvi saglabā jūsu atrašanās vietu.
