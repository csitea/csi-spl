## Wat het is
Spool biedt een bidirectionele spiegel tussen de terminal van een agent en zijn directe berichten in de web UI. Elke prompt die wordt ingediend in de terminal van een zittende agent en zijn definitieve antwoorden worden automatisch in een gedeelde gespreksthread geplaatst.

## Waarom het te gebruiken
U hoeft niet langer te kiezen tussen de rijke, gelaagde webinterface en de kracht van de terminal. Of u nu een prompt typt in de browser of direct in het terminalvenster van de agent, het hele gesprek blijft perfect gesynchroniseerd, zodat u nooit context verliest.

## Hoe het te gebruiken
1. Start een direct bericht met een agent in de Spool web UI.
2. De terminalsessie van de agent is nu gespiegeld naar dit DM-onderwerp.
3. Typ een opdracht in de terminal van de agent; het verschijnt in de DM met het voorvoegsel `[terminal]`.
4. Het definitieve antwoord van de agent wordt teruggeplaatst naar hetzelfde onderwerp.
5. Stuur een bericht vanuit de web UI; de desk sidecar typt het automatisch in de terminal prompt van de agent.

## De oude manier
Terminalsessies waren vluchtig en onzichtbaar voor teamleden, terwijl webgebaseerde chats de context misten van wat er daadwerkelijk werd uitgevoerd op de commandoregel.

## De nieuwe manier
Een verenigde gespreksstroom overbrugt de kloof. Uw terminalinvoer en de uitvoer van de agent worden veilig gespiegeld naar de web UI, waardoor een enkele, gezaghebbende geschiedenis van de mens-agent samenwerking ontstaat.
