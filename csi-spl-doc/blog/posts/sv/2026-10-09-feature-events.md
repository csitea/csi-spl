**Vad det är**
Fliken Events (ikonen 🕘 i vänsterfältet) tillhandahåller en personlig aktivitets- och diagnostiklogg. Den registrerar viktiga händelser och fel för din inloggade session och fungerar som ett privat diagnostikverktyg.

**Varför använda den**
När du stöter på ett problem eller behöver rapportera ett fel ger händelseloggen exakta detaljer. Den listar fel-ID:n, källor och läsbara meddelanden, vilket gör det mycket enklare att felsöka problem eller be om hjälp.

**Hur man använder den**
1. Klicka på **Events** i vänsterfältet eller öppna `/events`. Du måste vara inloggad.
2. Loggen visas som en tabell med tidpunkt, fel-ID, källa, status och meddelande för varje händelse.
3. Om du behöver rapportera ett problem anger du Error ID från loggen.
4. Du kan klicka på knappen **Clear log** för att rensa din personliga händelselogg.

**Det gamla sättet**
Före händelseloggen förlitade sig felsökningen på vaga felmeddelanden eller grävande i webbläsarens utvecklarverktyg, vilket gjorde det svårt att rapportera problem korrekt.

**Det nya sättet**
Varje fel eller anmärkningsvärd händelse sparas automatiskt i en tydlig, lättläst tabell direkt i appen. Du kan direkt se vad som hände och få det exakta fel-ID som behövs för support.
