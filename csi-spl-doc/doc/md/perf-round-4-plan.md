# Performance round 4: 30 practices x 2 changes (plan, 2026-10-03)

Owner, t1 #spool-hub-ops: "Performance round" / "30 best practices for performace. For each one perform 2 changes on the src. 4 agents per box at atime".

This lane plans and measures. It changes no product code. Each row is one lane with its own brief; the run order below is the biggest measured gain first. Sources: round 3 (`perf-audit-round3-2026-10-02.md`) and the DB payload rounds; open round-3 items are reused where they fit a practice (P3-05, P3-07, P3-08, P3-09, P3-10, P3-11, P3-12, P3-18, P3-28, P3-29). P3-26 is dropped: its 25..40 ms is a sourcemap mis-mapping onto the composer dock, which another lane owns.

## 1. Rules for every lane

- Measured on trunk `2ea249ff`. Every site carries its measured cost now and its n. A change that shows no gain is dropped and reported, never shipped.
- The 60 files are pairwise distinct, disjoint from refactoring round 1 (`refactor-round-1-plan.md`, its 69 files), and off msg/msg.go, store/fleet_*.go, migrations and the rotation/lease/spawn scripts. A lane touches only its two sites' files (plus new test files beside them).
- Done means: on master through the pre-push gate; hub or WUI runtime changes deployed to dev AND prd with the served version checked; before/after numbers with n.
- Box: `satellite` = runs on the satellite box; `main` = needs the main box (self-hosted runner timings, deployed-host proofs); `either`.

## 2. How it was measured

- **Hub:** `go test -bench -benchmem -count=6` (median; B/op and allocs/op exact), DB round trips through the counting pgProxy of `onsend_bench_test.go` against a private postgres:16-alpine plus the PG statement log (n=5, identical every run). The moveEnv rig has the door cache off, so quote deltas, not absolutes.
- **WUI:** a mock `nuxt generate` with sourcemaps, served with Hosting's headers over h2, driven by puppeteer-core: sourcemapped CPU profiles at m390 CPU 4x (n=3..5), DOM / listener / layout-read counts, node micro-benches (n=10..15), bundle bytes via attr.cjs (n=1 build). Box load average 12..25, so ms are noisy; the ratios hold.
- **Bash/CI:** `gh api` job and step durations of the last 10..12 successful runs (median), per-test-file times from job logs (n=3), `time` (n=5) and `strace -f -c` locally.

## 4. Risks and notes per lane

- **C4** wf11 uses 3x hosted minutes; error-vs-ratchet exit codes must stay distinct
- **C2** tests sharing fixed /tmp, $HOME or tmux state race: mark them `# serial` and run them after the pool
- **W7** e2e that read rail DOM at once (see 1b04caf7); mobile-stack route panels must still open from a URL; Re-run `lane-map.sh --check` first: c-017@sat (topic drag) and c-013@sat (Topics list) may touch ChannelSidebar.vue.
- **C1** low: `${x##*/}` then `%.func.sh` equals `basename x .func.sh` for these paths
- **W4** sub-pixel canvas/DOM differences: keep the pad
- **C6** an image pushed for a red commit sits unrolled in the registry; `do_release_version` tag minting must still wait for green; Also build the hub image ONCE for both env legs if the image is env-independent (both legs today build it: dev 52 s, prd 50 s, n=12) - same file, same lane.
- **G2** the set read must keep per-channel RLS/visibility
- **G1** a memo kept past the request serves stale membership: scope it to the request ctx
- **G3** statement order and error mapping inside the batch
- **G5** keep the FOR UPDATE inside the CTE; same locking semantics
- **G4** `queryTenantBatch` keeps the RLS scope; `ErrNotFound` mapping unchanged
- **C5** a cache must not mask a broken Dockerfile (cold path on key change); an ~80 MB artifact up/down may eat the wf10 gain - drop that site if so
- **W10** the cookie choice must still beat Accept-Language
- **W9** high: a stale shell after a deploy. If the swap test is not airtight, drop the item
- **C7** warms only the POPs the runner reaches; base URL from cnf/env, never a literal host; Do NOT edit 30_wui-build-deploy.yml (C6 owns it): trigger from a new workflow_run workflow.
- **G11** plan price staleness <= 5 min; flow must stay private (`private, no-cache`)
- **W3** pane width / strip state must not flash on the first frame
- **W5** `--kb-inset` timing while the keyboard opens; Not the omnibox/dock files (c-047).
- **W1** a non-ASCII human label sorts differently: keep localeCompare for human names
- **C3** low: the key must include the version pin
- **G9** `Canonical` is the signature contract: output byte-identical or drop the site
- **G8** the raw-write helper keeps the write timeout and lock; `trimWUIEnv` in wui.go has G9's cost shape (41 us / 5.9 KB / 93 allocs per frame, n=6): fold it in here if cheap; do not edit view.go/wire.go (G9).
- **G12** JSON field set must stay identical; hub/edit_test.go is c-044's, so new tests go in a new file
- **G10** never retain a pooled buffer after `finish`; cap the size returned to the pool
- **G6** do not touch hub/reactions.go (c-044's)
- **G7** confirm the walk does not depend on the clones read first; drop that site if it does
- **W2** collator options must equal today's (`numeric:true, sensitivity:'base'`)
- **W6** focus on first open (lazy-dialog focus race); Re-run `lane-map.sh --check` first: c-015@sat (bell) may touch TopBar.vue; not the omnibox (c-047).
- **W8** spool-client.mjs imports `noteError` statically and the notification store is imported by channel/topic stores: if the bytes do not leave the initial chunk, drop the site; do not edit spool-client.mjs
- **W11** callers become async; a destructured utils/ import becomes a static auto-import (the P3-15 trap: read it as a member)
