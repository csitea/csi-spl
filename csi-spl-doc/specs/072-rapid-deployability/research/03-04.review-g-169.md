5. **Global names have no escape, so A8's own fixture is illegal.** `cloud.py:64` rejects any project id other than `{ORG_APP}-{ENV}`. `gcp-001-create-project.func.sh:71` is `proj_id="${ORG}-${APP}-${ENV}"`. A8's done-when is a fixture `gcp_project: acme-spool-dev-7f3a`. That string is not `{org}-{app}-{env}`. Nine regexes then refuse the buckets and the site id that would follow a different project id.
6. **A copied dev file points DNS at this estate's prd project** (`dev.env.yaml:79` and `:156`) and carries this estate's tenant list (`:25`).
7. **The cnf README denies keys the package contains** (`csi-spl-cnf/README.md:8` vs `all.env.yaml` `gcp_org_id`). A newcomer who trusts the README will not look for the silent default 072 F11 describes.
8. **Satellite cost and the budget disagree, and spec 057's machine type is stale.** `e2-standard-16` in prd cnf, `e2-highmem-4` in 057 §5.3, budget 170 against a ~$431 list price (§1.4). A newcomer who leaves the step on learns this from an invoice. A16's ~$0.05 figure is the clean-room path with 060 off, not this machine.
9. **Registrar actions assume one vendor.** Six `gandi-*.func.sh`. Another registrar has no named action for the NS handoff the contract's row 3a requires. That is a docs gap, not a reason to add a seventh vendor SDK.
