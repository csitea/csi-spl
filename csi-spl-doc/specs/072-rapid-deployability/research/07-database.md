## 2. Blockers

Ranked by spec 072 section 2.

1. **Every cloud DB action refuses any env but dev and prd.** One shared
   guard, `csi-spl-orc/lib/bash/funcs/spl-cloud-cnf.func.sh:21`
   (`[[ "$e" == dev || "$e" == prd ]]`), is inherited by
   `do_spl_db_bootstrap`, `_backup`, `_restore`, `do_spl_backup_offsite` and
   `do_spl_tenant_create`. Step 040 repeats it:
   `040-cloud-sql-postgres/02-variables.tf:16` (env) and `:37`
   (instance name regex pinned to our prefix and `dev|prd`). 072 G9 counts the
   tf half; the orc half is not in its table yet.
2. **The off-project backup assumes our second GCP project.** 046 pins its
   project and bucket names by regex
   (`grep -n 'regex' csi-spl-iac/src/terraform/046-gcs-offsite-backups/02-variables.tf`
   -> lines 31, 41), and `copy_enabled: true` is the cnf value a copier
   inherits (`grep -n copy_enabled csi-spl-cnf/csi-spl/{dev,prd}.env.yaml`
   -> lines 245, 252). Same as 072 G13.
3. **The first cloud tenant is two commands and a hand-captured private key**
   (1.3 rows 4-5); on an env cnf'd like `dev`, the gap between them lets the
   first stranger who signs in own the tenant.
4. **P1 backups are a pasted line**: unscheduled, never off the machine, never
   restore-tested, never run by CI (1.2, second table). The only copy of the
   root key sits in the same volume set as the data.
5. **Schema drift is silent at start.** An old hub binary on a newer schema,
   or a new binary on an un-migrated database, starts and then fails per
   request (1.1: the `spool_schema_migrations` grep -> 0). Compose forces the
   order on P1 and wf 20 on P2; a hand-run container or a skipped bootstrap
   has no guard.
6. **The migration rules are prose, not a test**: the duplicate `0021`
   (1.1) proves it. Forward-only means it can never be renamed, and with 89
   commits in 13 days two lanes taking the same "next free" number is likely.
7. **Stale comment:** 040's header still tells the owner to run
   `gcloud sql users create` and `gcloud secrets versions add` by hand
   (`03-cloud-sql.tf:9-13`), which `do_spl_db_bootstrap` replaced. A stranger
   who reads the tf first does the manual steps.
