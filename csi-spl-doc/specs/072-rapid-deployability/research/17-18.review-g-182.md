runs Postgres, the hub and the WUI, and the hub process does not call Cloud

default id is a legacy form the write path stopped accepting on

## 2. Blockers

1. **The in-app connect guide hides its only block.** Default `CLE-01`
   (`ConnectAgentGuide.vue:62`) fails `isWritableAgentId` after
   `agent-id.mjs:20`. The error text teaches the id it rejects. Code read,
   n = 1, not a click.
2. **Three connect procedures.** README `install.sh --env self`, the help
   page (7 times `CLE-01`), and the settings guide (go build plus a Downloads
   key path). A newcomer who follows two of them does different work.
3. **No published image.** Every first start compiles the hub and the WUI.
   Spec 047 section 1.1 measured 241 s of a 6 min 26 s first message (tree
   `4dc8df91`, n = 1, a loaded machine, an upper bound). Not re-timed here.
4. **`./run --help` advertises `do_help_with`, which has no file**
   (`print-help.func.sh:70`; 0 paths matching `help-with`). 238 + 93 actions,
   one flat list, no groups.
5. **The doc index opens on the relay how-to** (`csi-spl-doc/README.md:3`)
   while line 15 says that file is the git-rel estate. The spec index itself
   is one section lower (line 9).
6. **Module READMEs are behind the tree.** Iac names 8 terraform rows against
   18 step directories. The API README names verbs the root README no longer
   uses.
7. **Getting started recommends social sign-in** (`getting-started.md:29`)
   on a stack whose compose file sets no provider.
8. **The directory driver is documented as local-dev only** (`blob.go:2-4`)
   while compose uses it for the standalone product. Not a missing service.
   A second node is out of this shape: the only remote store is the GCS
   driver, and the cloud-provider seam is parked (spec 072 section 3.1).

None of 1-8 is a hard dependency on Cloud Run, the git-rel bucket, Firebase
or Secret Manager.

## 5. Where I disagree

Research 17 (`17-local-all-in-one.md`, c-166, tree `79a10ef4`) and research

Both are on `origin/master`. Spec 072 has since folded much of them in

### 5.1 With research 17

Agreed, and re-checked on `efa8faf38`: the mode is already shipped; one
non-test storage import; 0 Secret Manager Go files; 0 `relay_bucket` hits
under the API and the WUI; compose sets the directory and not a bucket. The
git-rel bucket needs no local stand-in. Do not build one.

Disagree on rank. Their top action is an `env_file` so the compose hub can
see the hosted-only settings (their N17.1, now A57), and their second is an
S3 store now (N17.2, their Q2). The first hour does not need either. Social
sign-in is more steps than the email form the local profile already shows.
An S3 service is another process to run, and the owner has since parked that
seam (spec 072 section 3.1, v0.5). One machine is the promise of the compose
file. Their L7 is half right: `do_spl_box_deploy` refuses `self`, but desk
pin already accepts it (`spl-desk-pin.func.sh:22`), and the README installer
uses that path.

### 5.2 With research 18

Agreed: the README quick start is the right door; `do_help_with` is a dead
tip; the iac and API READMEs are stale; CONTRIBUTING requires a sign-off that
0 of the last 200 commits carry. Their `./run` counts (241 and 96) were on
`324062214`. On `efa8faf38`, excluding pre and post hooks, the counts are
238 and 93. Same conclusion.

Disagree that the friction of the local path is "build time and the long
seat line, not the prose." The prose of the root README is fine. The in-app
guide is not: blockers 1 and 2 above are absent from research 18, from
research 17, and from `spec.md` (`git grep CLE-01` and `ConnectAgentGuide`
under `csi-spl-doc/specs/072-rapid-deployability/` on the trees read here
returned no lines). Their claim that `csi-spl-doc/README.md` stops its spec
table at 011 is not this tree: line 9 points at `specs/README.md`. The fault
that remains is line 3, the relay doc introduced as what the spool is.

Their top three (a choose-your-path block, a navigable `./run --help`, errors
that end with the next command) are right for the action catalogue and are
already A15 and A58. They rank behind N1, because a signed-in admin who opens
Connect an agent does not get a block to paste.
