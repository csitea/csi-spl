# 110 Mistral vendor: tasks

Authority for what is built. `spec.md` holds the behaviour; this file
follows its sections 2-4. Each task names its layer, its dependency, the
files it owns, and a Done line with its test pair from `spec.md` section 7.
Status vocabulary: `../README.md` item 3 (`[x]` Implemented, `[~]` Partial /
in progress in a live lane, `[ ]` Planned).

Version **v0.1**, built from the 109-file qwen touch list
(`git grep -il qwen -- ':!*.md'` at `0b38b6ff3`) plus the 20 grammar readers
outside it (`spec.md` 3.2). Every one of those 129 files is owned by exactly
one task below, or is named there as read-only:

- `spawn-qwen.sh` and `restore-qwen.sh` are templates only. The
  qwen/grok/agy launchers are not edited.
- The old migrations `0101`, `0102`, `0109`, `0110` and `0149` are
  forward-only history. T001 supersedes them.

**Path prefixes:**

- Go paths are under `csi-spl-api/src/go/spool-hub-api/internal/`.
- `SA/` is `csi-spl-orc/src/bash/features/spawn-agents/`.
- `RUN/` is `csi-spl-orc/src/bash/run/`.
- `OT/` is `csi-spl-orc/src/bash/tests/`.

A migration takes the next free prefix at commit time.
`.shellcheck-warning-baseline.txt` is regenerated by whichever task shifts a
listed line; it is not owned by any one task.

**Owner questions** are in `spec.md` section 8. Q1 (data rule) changes
nothing here. Q2 (plan) changes only T014. Q3 (timing) changes only T013.

owner's login. T013 is last.
