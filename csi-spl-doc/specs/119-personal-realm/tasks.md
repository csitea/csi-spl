# 119 Personal realm: tasks

Authority for what is built. `spec.md` holds the behaviour; this file
follows its sections 7 (schema, policy, grants), 8 (receipts, copy first),
9 (the 118 contract C1..C7) and 11 (tests). Each task is one small lane:
its layer, its agent kind, what it waits on, the files it owns, the files it
must not touch, and a Done line with its tests from `spec.md` section 11.
Status vocabulary: `../README.md` item 3 (`[x]` Implemented, `[~]` Partial /
in progress in a live lane, `[ ]` Planned).

Version **v1.0**, built from `spec.md` v1.1 (`0cba1e6c4`). The owner's go:
"Okay, start implementation." (t1 151d85fc, HUM-10, msg da5e579d).

**Path prefixes:**

- `GO/` is `csi-spl-api/src/go/spool-hub-api/internal/`.
- `RDB/` is `csi-spl-rdb/src/sql/postgres/`.
- `RUN/` is `csi-spl-orc/src/bash/run/`; `OT/` is `csi-spl-orc/src/bash/tests/`.
- `WUI/` is `csi-spl-wui/src/`.

**Rules for every lane:**

- Store, RLS and auth tests run on Postgres as the runtime role
  (`PRE_PUSH_TIER=full ./run -a do_check_pre_push`), never as the owner or a
  superuser. Every RLS test has its red control (`spec.md` 11), made on a
  throwaway branch, never on trunk.
- A file is owned by exactly one lane below. A lane that needs a change in a
  file it does not own asks that lane's agent, or the orchestrator if that
  lane has landed.
- `.shellcheck-warning-baseline.txt` is regenerated by whichever lane shifts
  a listed line; no lane owns it.
