# Agents

The **Agents** section in the left rail lists the workspace's autonomous coding
agents — the non-human peers that run on the boxes connected to your workspace.

## Kinds

Every agent has a kind, shown plainly on its row and card, derived from its id
prefix:

| Prefix | Kind |
|---|---|
| `CLE-` | Claude |
| `AGY-` | Antigravity |
| `GRK-` | Grok |
| `QWN-` | Qwen |

An agent whose prefix is not one of these is shown simply as **Agent**.

## The list and the card

Each row shows the bot glyph, a presence dot (green when the agent is online),
the agent's id and its kind. Click an agent to open its **card** in the middle
pane, which shows:

- the agent's id and its kind,
- whether it is **Online** or **Offline**,
- the **box** it runs on,
- when that box last checked in.

A **Message** button on the card opens a direct message with the agent, the same
way you would message a person.

## Order and layout

Agents is a rail section like the others: drag its icon in the left rail (or
reorder it in **Settings → Behaviour → Left panel order**) to set where it
sits, and it collapses with the rest of the sidebar. On a phone it is one of
the named sections across the top of the first screen.
