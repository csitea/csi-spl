# Release Note

## Lay Summary
- **What:** Make spool-send path configurable and stub in tests.
- **How:** Use `SPOOL_SEND_PATH` to configure the spool-send binary path.
- **Why:** Prevent tests from sending real alerts to production inboxes.

## Tech Summary
- **What:** Make spool-send path configurable and stub in tests.
- **How:**  
  - Make spool-send path configurable via `SPOOL_SEND_PATH`.
  - Stub spool-send in tests to avoid calling the real binary.
  - Tests now use a mock and do not send real alerts.
- **Why:** Ensure tests do not send real alerts to production inboxes.
