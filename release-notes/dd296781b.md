# Release Note

## Lay Summary
- **What:** Ensure all spool-send calls use `SPOOL_SEND_PATH`.
- **How:** Replace hard-coded spool-send paths with `SPOOL_SEND_PATH`.
- **Why:** Prevent tests from sending real alerts to production inboxes.

## Tech Summary
- **What:** Ensure all spool-send calls use `SPOOL_SEND_PATH`.
- **How:**  
  - Replace hard-coded spool-send paths with `SPOOL_SEND_PATH`.
  - Tests now use a mock for all spool-send calls.
- **Why:** Ensure tests do not send real alerts to production inboxes.
