# Release Note

## Lay Summary
- **What:** Automated monitoring for public HTTPS certificate expiry.
- **How:** A new check `do_net_cert_expiry_check` warns at <= 21 days and alarms at <= 7 days.
- **Why:** Prevent downtime from expired certificates.

## Tech Summary
- **What:** Implement `do_net_cert_expiry_check` in `csi-spl-utl` for TLS certificate expiry monitoring.
- **How:**  
  - Dynamic endpoint discovery from `BASE_DOMAIN`.
  - Uses `openssl x509 -checkend` to warn at <= 21d and alarm at <= 7d.
  - Sends throttled spool note to orchestrator on threshold crossing.
  - Outputs days remaining (e.g., `63d`) and completes in < 2s.
- **Why:** Ensure certificates are renewed before expiry to avoid service disruption.
